# AgriVisionAI
🚀 Introducing AgriVisionAI — AI-powered early detection for plant health🌱

⚡Key Features

• AI-based leaf disease detection using image input
• Structured insights generated from model predictions
• Downloadable PDF reports for easy sharing and record-keeping
• Location-based trending section for latest updates on crop diseases

⚡ How it works

• Image classification powered by EfficientNet-B
• Insight generation using LLaMA (via Groq) for structured output interpretation
• Backend built with Flask

⚡The goal is to bridge the gap between AI and agriculture by providing accessible, fast, and actionable insights for farmers and researchers.
